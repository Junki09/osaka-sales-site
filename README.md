# 大阪営業所 成績ボード

コール数・アポ数・商談実施数・受注率(自アポ／他アポ)・失注理由・商材別成績・戦略/戦術メモを管理する社内サイトです。
データベースには Firebase Realtime Database（無料）を使い、チーム全員が同じデータをリアルタイムで見られるようにしています。

## 1. Firebaseのセットアップ（無料）

1. https://console.firebase.google.com を開き、Googleアカウントでログインします。
2. 「プロジェクトを追加」から新規プロジェクトを作成します（Googleアナリティクスは無効のままで問題ありません）。
3. 左メニューの「構築」→「Realtime Database」を開き、「データベースを作成」を押します。
   - ロケーションは `asia-southeast1`（シンガポール）などお好みの近いリージョンでOKです。
   - セキュリティルールは、まず「テストモードで開始」を選びます（誰でも読み書きできる状態です）。
4. データベース作成後、「ルール」タブを開き、以下のように設定して「公開」します（社内利用の簡易ツール向けの設定です）。

```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```

社外に漏れると困る場合は、後述の「運用メモ」を参照してください。

5. 画面左上の歯車アイコン →「プロジェクトの設定」→「全般」タブの一番下、「マイアプリ」で「</>」（ウェブ）を選び、アプリを登録します。
6. 表示される `firebaseConfig` の中から、以下の4つの値をメモします。
   - `apiKey`
   - `authDomain`
   - `databaseURL`
   - `projectId`

## 2. ローカルでの動作確認

```bash
npm install
cp .env.example .env
# .envを開いて、上記4つの値を書き込む
npm run dev
```

ブラウザで表示されたURL（例：http://localhost:5173）を開いて動作確認します。

## 3. 自社ドメインで公開する

おすすめは Vercel（無料枠あり・自社ドメイン接続も可能）です。

1. このプロジェクトをGitHubリポジトリにpushします。
2. https://vercel.com でGitHub連携し、このリポジトリを「Import」します。
3. 「Environment Variables」に、`.env`と同じ4つの値（`VITE_FIREBASE_API_KEY` など）を設定します。
4. デプロイ完了後、Vercelの「Settings」→「Domains」で自社ドメイン（例：sales.your-company.co.jp）を追加し、
   案内されるDNSレコード（CNAMEなど）を自社のドメイン管理画面に設定します。

Netlifyでも同様の手順で公開できます。

## 4. 運用メモ

- 営業メンバーの登録は「営業メンバー」タブから行います。
- 「アポ・商談」タブで企業名とアポ獲得者を登録し、訪問後に商談担当・結果・失注理由を更新します。
  自アポ／他アポの受注率は、アポ獲得者と商談担当者が同じか異なるかで自動的に振り分けられます。
- 「戦略・戦術」タブは対象者ごとに、月間・週間の戦略/戦術を5項目ずつ入力できます。
- 現状は認証なしで社内リンクを知っている人なら誰でも閲覧・編集できる設定です。
  外部に漏れると困る場合は、Firebase Authenticationでログイン画面を追加することを検討してください。
